## Otázka 1: Vědecké názvy ptáků

Napište vědecký název veškerého ptactva, které splňuje současně následující kritéria: vyskytuje se v Evropě, je téměř ohrožené a jsou hmyzožravci.

### Odpověď:

Na základě analýzy dostupného datasetu nejsou v databázi žádní ptáci, kteří by současně splňovali všechna tři kritéria (výskyt v Evropě + status "Téměř ohrožený" + typ potravy "hmyzožravec").

V datasetu se vyskytují ptáci s individuálními kritérii:
- **Hmyzožravci v Evropě**: Vlaštovka obecná (Hirundo rustica), Datel černý (Dryocopus martius), Kukačka obecná (Cuculus canorus) - ale všechny mají status "Málo dotčený"
- **Téměř ohrožený pták**: Tučňák císařský (Aptenodytes forsteri) - ale z Antarktidy, ne z Evropy a je masožravec

## Otázka 2: SQL dotaz

Napište SQL dotaz, kterým lze získat informaci z předchozí otázky. Budete muset najít způsob, jak takový dotaz získat. Do odpovědi nevkládejte dotaz, který obsahuje proměnné.

### Odpověď:

```sql
SELECT vedecky_nazev, nazev, status_ohrozeni, typ_potravy, vyskyt_kontinent
FROM bird
WHERE vyskyt_kontinent = 'Evropa'
AND status_ohrozeni = 'Téměř ohrožený'
AND typ_potravy = 'hmyzožravec';
```

Tento SQL dotaz byl zjištěn studiem modelu databáze v souboru [models.py](../models.py), kde jsou definovány sloupce Bird tabulky. Dotaz filtruje záznamy podle tří podmínek:
- `vyskyt_kontinent = 'Evropa'` - výskyt v Evropě
- `status_ohrozeni = 'Téměř ohrožený'` - status ohrožení
- `typ_potravy = 'hmyzožravec'` - typ potravy

## Otázka 3: Jak se do HTML šablony dostanou data o ptactvu

Jak se do HTML šablony dostanou data o ptactvu, která si uživatel nechal vypsat s použitím filtru? Do odpovědi vložte volání funkce, kde se tak děje.

### Odpověď:

Data se do HTML šablony dostanou přes funkci `index()` v [main.py](../main.py):

```python
@app.route('/')
def index():
    birds = Bird.query.all()
    return render_template('index.html', birds=birds)
```

V tomto příkladu se všichni ptáci načítají z databáze pomocí SQLAlchemy ORM (`Bird.query.all()`) a poté se předají šabloně `index.html` jako proměnná `birds`. 

V šabloně [index.html](../templates/index.html) se data iterují v Jinja2 smyčce:

```html
{% for bird in birds %}
<tr>
    <td>{{ bird.nazev }}</td>
    <td>{{ bird.vedecky_nazev }}</td>
    <td>{{ bird.status_ohrozeni }}</td>
    <td>{{ bird.typ_potravy }}</td>
    ...
</tr>
{% endfor %}
```

Důležitá volání:
- `render_template('index.html', birds=birds)` - předání dat šabloně
- `{{ bird.vedecky_nazev }}` - vykreslení dat v šabloně

## Otázka 4: JS knihovna pro zobrazování grafů

Jakou JS knihovnu používáte pro zobrazování grafů? Odkud se stahuje?

### Odpověď:

**Aplikace nepoužívá žádnou JS bibliotéku pro zobrazování grafů.**

Místo toho se používá **Python matplotlib** (verze 3.5.3) na backendu pro generování grafů. Grafy jsou vytvářeny na serveru a poté se převádějí na obrázky (PNG formát).

Proces:
1. Na serveru se grafy generují pomocí matplotlib v [main.py](../main.py):
```python
fig, ax = plt.subplots()
df['delka_cm'].dropna().plot(kind='hist', ax=ax, title='Délka Distribution (cm)')
plots['delka'] = get_plot_img(fig)
```

2. Graf se zakóduje do Base64 formátu a odešle do šablony:
```python
def get_plot_img(fig):
    img = io.BytesIO()
    fig.savefig(img, format='png')
    img.seek(0)
    plot_url = base64.b64encode(img.getvalue()).decode()
    plt.close(fig)
    return plot_url
```

3. V HTML šabloně [stats.html](../templates/stats.html) se vloží jako Base64 zdroj:
```html
<img src="data:image/png;base64,{{ plots.delka }}" class="img-fluid" alt="Délka Distribution">
```

**Jedinou JS knihovnou** v aplikaci je **Bootstrap** (verze 5.1.3), která se stahuje z CDN:
```html
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.1.3/dist/js/bootstrap.bundle.min.js"></script>
```

Bootstrap se používá pouze pro responzívní design a CSS styling, ne pro interaktivní grafy.
